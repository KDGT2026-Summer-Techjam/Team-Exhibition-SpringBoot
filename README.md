# シオリー（Shiory）

## 開発環境

### Backend

- Java: OpenJDK 17.0.16
- Spring Boot: 4.0.8
- Maven: 3.9.12
- PostgreSQL: 構築中
- OS: macOS / Windows

### 使用ライブラリ

- Spring Web MVC
- Spring Data JPA
- Spring Validation
- PostgreSQL Driver
- Lombok
- Spring Boot Test

## 起動方法

### 1. リポジトリをクローン

git clone https://github.com/KDGT2026-Summer-Techjam/Team-Exhibition-SpringBoot.git
cd Team-Exhibition-SpringBoot


### 2. Spring Bootを起動

./mvnw spring-boot:run
