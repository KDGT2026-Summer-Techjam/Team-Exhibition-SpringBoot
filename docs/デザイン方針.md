# しおりアプリ デザイン方針

## コンセプト

**ノート帳の1ページを開いているような UI** を目指す。

- 全体は **淡いベージュ** を基調にする
- **横罫線**（ノートの行）を背景や入力エリアに取り入れる
- 旅行のしおりを手書きで書き込むイメージ。温かみがあり、落ち着いたトーン
- 細部（フォント選定、影、角丸の強さなど）は UI 実装後に調整する

関連: [コンポーネント一覧.md](./コンポーネント一覧.md)

---

## カラーパレット（案）

実装時は CSS 変数（または Tailwind の theme）で持つ。

| トークン | 用途 | 色（案） |
|----------|------|----------|
| `--color-paper` | ページ背景・カード面 | `#F5F0E6`（淡いベージュ） |
| `--color-paper-deep` | しおりカード、モーダル | `#EDE6D6` |
| `--color-line` | 横罫線 | `#D4C9B8`（薄いグレーベージュ） |
| `--color-margin` | 左マージン線（任意） | `#E8B4B4`（淡いピンク／朱色） |
| `--color-ink` | 本文テキスト | `#3D3832`（墨色に近い茶グレー） |
| `--color-ink-muted` | 補足・ラベル | `#7A7268` |
| `--color-accent` | 主ボタン・リンク | `#8B7355`（落ち着いたブラウン） |
| `--color-accent-hover` | ホバー | `#6F5A42` |
| `--color-danger` | 削除・BAN | `#B85C5C` |

白 `#FFFFFF` は使わず、紙色の上に要素を載せるイメージに統一する。

## ノートの線の入れ方

### 横罫線（メイン）

ノートの **等間隔の横線** を CSS で表現する。

```css
/* 例: 28px 間隔の横罫 */
background-color: var(--color-paper);
background-image: repeating-linear-gradient(
  to bottom,
  transparent,
  transparent 27px,
  var(--color-line) 27px,
  var(--color-line) 28px
);
```

- 行間（28〜32px）は **本文フォントサイズと揃える**
- 線は主張しすぎない薄さにする（opacity 0.4〜0.6 でも可）

### 左マージン線（任意）

学校ノート風に、左端に **縦のマージン線** を1本入れる場合。

- 左から 48px 付近に縦線（`--color-margin`）
- しおり内容・日ごとページ（`DayPage`）に特に向く
- 一覧やログイン画面では省略してもよい

### 使い分け

| 要素 | 罫線の扱い |
|------|------------|
| ページ全体背景 | 薄い横罫 |
| `TextArea` / 備考・お約束 | 横罫付き（入力が線の上に乗る） |
| `ItineraryCard` | 紙色＋軽い罫 or 罫なし＋細い枠 |
| `Modal` | 罫なし（紙の切れ端。影で浮かせる） |
| `PhotoGrid` | 罫なし（写真は枠・余白で区切る） |

罫線を **全面に敷きすぎない**。読みやすさ優先で、フォームとしおり本文に集中させる。

## タイポグラフィ（案）

確定は後。方向性のみ。

| 用途 | 方向性 |
|------|--------|
| 見出し（しおりタイトル、◯日目） | やや手書き風 or セリフ（ノートの見出し感） |
| 本文・フォーム | ゴシック系で可読性重視（罫線との相性） |
| ラベル・日付 | 小さめ、muted 色 |

Google Fonts 候補（後で選定）:

- 見出し: `Zen Maru Gothic`, `Klee One`, `Shippori Mincho`
- 本文: `Noto Sans JP`, `Zen Kaku Gothic New`

## コンポーネントへの当て方

### 共通 UI

| コンポーネント | デザイン |
|----------------|----------|
| `Button` | 紙色背景＋インク色枠、または accent 塗り。角はやや丸（`rounded-md` 程度） |
| `TextField` | 下線のみ（ノートに書く一行）or 薄い枠＋白ではなく paper 背景 |
| `TextArea` | **横罫背景**＋透明背景。padding で1行目が罫に揃う |
| `Modal` | `paper-deep` 背景、軽い shadow。罫線は付けない |
| `AppHeader` | 罫線なし。下に細い `--color-line` の border のみ |

### しおり一覧

- `ItineraryCard`: 小さな **紙のカード**（微細な shadow、角丸）
- カード内は罫1〜2本だけ、またはタイトル下に点線

### しおり内容（中心画面）

- `DayPage`: **フル罫線**＋左マージン（任意）
- `RoadmapItem`: 時刻を左マージン側、予定を罫の上に配置
- `CommentThread`: 罫より薄い背景で吹き出し風（線を邪魔しない）

### 写真

- グリッドは **ポラロイド／貼り付け写真** 風も検討（後段）
- 初期実装はシンプルな枠＋ paper 背景

---

## レイアウト・余白

- ページ左右に **ノートの余白**（24〜32px）
- 最大幅を 720px〜840px 程度に制限し、1枚のノートを中央に置く
- スマホでも罫線は維持し、行間だけ少し詰める

---

## 実装メモ（Next.js）

1. `app/globals.css` に CSS 変数と `.notebook-bg` / `.notebook-lined` ユーティリティを定義
2. Tailwind を使う場合は `theme.extend.colors` に paper / line / ink を追加
3. 罫線は **画像ではなく CSS gradient** で描く（解像度・ダークモード対応が容易）
4. ダークモードは **初版スコープ外**（ベージュノートがコンセプトのため）

---

## この段階で決めないこと

- 正確な hex 値（上記は起点。実装時に微調整）
- フォントの最終決定
- イラスト・アイコンの有無
- アニメーション（ページめくり等）

UI コンポーネントの骨格ができたら、この方針に沿って一括で見た目を当てる。
