# しおりアプリ 要件定義

## 概要

本ドキュメントは、しおりアプリの機能要件を画面単位でまとめたものである。

| 項目 | 説明 |
|------|------|
| ターゲットユーザー | 未記入の場合は空欄とする |
| 優先度 | Must など。未記入の場合は空欄とする |
| リリース対象 | 未記入の場合は空欄とする |

---

## 画面一覧

| # | 画面 | 概要 |
|---|------|------|
| 1 | [アカウント新規登録画面](#1-アカウント新規登録画面) | ユーザー名・パスワード・メールアドレスの登録 |
| 2 | [ログイン画面](#2-ログイン画面) | メールアドレスまたはユーザー名とパスワードでログイン |
| 3 | [しおり一覧画面](#3-しおり一覧画面) | 参加中のしおり一覧の表示・退出・詳細遷移 |
| 4 | [しおり作成](#4-しおり作成) | 新規しおりの登録 |
| 5 | [しおり内容](#5-しおり内容) | 日ごとのしおり編集、写真、コメント、権限設定 |
| 6 | [しおり管理](#6-しおり管理) | 作成者向けのメンバー管理・しおり設定変更 |
| 7 | [招待受領画面](#7-招待受領画面) | 招待されたしおりへの参加 |
| 8 | [設定画面](#8-設定画面) | アカウント情報の変更・ログアウト |

## 5. しおり内容

### 5.1 日ごとのページ

期間に応じて日ごとのページが自動生成される。

| 要件名 | 詳細 | ターゲットユーザー | 優先度 | リリース対象 |
|--------|------|-------------------|--------|--------------|
| しおり◯日目（旅の予定期間で自動配置） | 期間に応じて日ごとのページが自動生成される。 | 一般ユーザー | Must | |
| - タイトル（表示 / 編集） | 1日ごとのタイトルを入力できる。 | 一般ユーザー | Must | |
| - ロードマップ（表示 / 編集） | カレンダー形式で予定を登録。必要に応じて予定ごとに使用金額を設定できる。 | 一般ユーザー | Must | |
| - 備考（表示 / 編集） | その日何をするか、何を食べるかなどをメモできる。 | 一般ユーザー | Must | |
| - 概算（表示 / 編集） | 1日単位の概算費用を表示できる。 | | | |
| - 写真登録（表示 / しおり管理者のみ登録） | 全員が登録した写真の中から1枚選択して、その日の代表写真として表示できる。 | 一般ユーザー | Must | |
| - お約束（表示 / 編集） | 旅のお約束・ルールを記入できる。 | | | |

### 5.2 コメント・権限・遷移

| 要件名 | 詳細 | ターゲットユーザー | 優先度 | リリース対象 |
|--------|------|-------------------|--------|--------------|
| しおりコメント（表示 / 投稿 / 編集 / 削除） | しおり内の記述要素（タイトル、タイトル補足、期間、◯日目タイトル、ロードマップの予定1件、備考、概算、代表写真、お約束、写真）それぞれに単体でコメントできる。各要素の横の＋から登録・編集・削除し、対象の近くに表示する。ロードマップは「21時の予定」など時刻付きの1件単位。 | | | |
| しおり編集権限設定（on / off）管理者のみ | 管理者がしおり編集の可否を切り替えられる。 | | | |
| しおりコメント解放設定（解放 / 未解放）管理者のみ | コメント機能の ON/OFF を管理者が設定できる。 | | | |
| 戻るボタン | しおり一覧に戻れる。 | | | |

### 5.3 写真一覧

| 要件名 | 詳細 | ターゲットユーザー | 優先度 | リリース対象 |
|--------|------|-------------------|--------|--------------|
| 写真一覧 | そのしおりに登録された写真一覧を表示する。 | | | |
| - 写真閲覧 | 写真を横3列のグリッドで表示する。 | | | |
| - 写真詳細 | 写真をクリックすると1枚を拡大表示する。 | | | |

| – いいねボタン | 写真詳細（一覧から選んだ1枚）に対し、参加メンバーは何度でもいいねを付けられる。写真1枚あたりの合計上限は999。 | | | |
| - 写真登録 | 1日ごとに1人1枚の写真を登録できる。 | | | |
| - 写真差し替え | 登録済みの写真を別の写真に変更できる。 | | | |
| - 写真削除 | 削除時は黒い画像に置き換わる。 | | | |
| - 写真並び替え | 日付順・いいね順で写真を並び替えて表示できる。 | | | |
| - 写真絞り込み | 日付ごと・ユーザーごとの写真を絞り込んで表示できる。 | | | |
| 戻るボタン | 写真一覧からしおり内容に戻れる。 | | | |

## 補足

- パスワード（アカウント・しおり共通の文字数制約が明示されているもの）は **英数字10文字以上**。
- しおり内容の日ごとページは、しおりの期間から **自動生成** される。
- 写真登録は **1日につき1人1枚**。削除時は黒い画像に置き換わる。
- しおり編集権限・コメント解放設定は **管理者のみ** 操作可能。
- しおり管理画面は **しおり作成者のみ** 閲覧可能。
- ターゲットユーザー・優先度・リリース対象が空欄の項目は、元要件表でも未記入。
