# しおりアプリ API設計

## 概要

本ドキュメントは、しおりアプリの REST API エンドポイントをまとめたものである。

| 項目 | 説明 |
|------|------|
| ベースパス | `/api` |
| 認証方式 | セッションまたはトークン（ログイン後のリクエストに付与） |
| 関連ドキュメント | [要件定義.md](./要件定義.md) / [データベース設計.md](./データベース設計.md) |

### 命名上の対応

API パスでは `itineraries` / `schedules` / `albums` を使用する。DB テーブルとの対応は次のとおり。

| API 上の名称 | DB テーブル |
|-------------|------------|
| `itineraries` | `shioris` |
| `schedules` | `shiori_days`（◯日目） |
| `albums` | `photos` |
| `invitations/{code}` | `invitations.token` |

---

## 共通仕様

### 認証

- ログインが必要な API には、リクエストヘッダーに認証情報を付与する。
- 未認証の場合は `401 Unauthorized` を返す。
- しおり参加メンバー以外がアクセスした場合は `403 Forbidden` を返す。
- 作成者（管理者）のみ操作可能な API は、権限不足時に `403 Forbidden` を返す。

### パスワード制約

アカウント・しおり共通で **英数字10文字以上**（[要件定義.md](./要件定義.md) 参照）。

### 共通エラーレスポンス（例）

| HTTP ステータス | 意味 |
|----------------|------|
| `400 Bad Request` | リクエストパラメータ不正 |
| `401 Unauthorized` | 未ログイン |
| `403 Forbidden` | 権限不足 |
| `404 Not Found` | リソース不存在 |
| `409 Conflict` | 重複登録など |
| `422 Unprocessable Entity` | バリデーションエラー |

## 1. ユーザー系 API

### 1.1 新規登録

| 項目 | 内容 |
|------|------|
| Method | `POST` |
| Endpoint | `/api/users` |
| 認証 | 不要 |
| 概要 | ユーザー名・メールアドレス・パスワードでアカウントを作成する |

**リクエストボディ（例）**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `username` | string | ○ | ユーザー名 |
| `email` | string | ○ | メールアドレス |
| `password` | string | ○ | パスワード（英数字10文字以上） |

**レスポンス（例）**

- `201 Created` — 登録成功
- `409 Conflict` — ユーザー名またはメールアドレスが既に使用されている

---

### 1.2 ログイン

| 項目 | 内容 |
|------|------|
| Method | `POST` |
| Endpoint | `/api/auth/login` |
| 認証 | 不要 |
| 概要 | メールアドレスまたはユーザー名＋パスワードでログインする |

**リクエストボディ（例）**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `loginId` | string | ○ | メールアドレスまたはユーザー名 |
| `password` | string | ○ | パスワード |

**レスポンス（例）**

- `200 OK` — ログイン成功（セッション／トークン発行）
- `401 Unauthorized` — 認証失敗

---

---

### 2.2 しおり作成

| 項目 | 内容 |
|------|------|
| Method | `POST` |
| Endpoint | `/api/itineraries` |
| 認証 | 必要 |
| 概要 | タイトル・パスワード・補足・期間を登録し、◯日目単位のページを自動生成する |

**リクエストボディ（例）**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `title` | string | ○ | しおりタイトル |
| `password` | string | ○ | しおりパスワード |
| `description` | string | — | タイトル補足 |
| `startDate` | date | — | 開始日 |
| `endDate` | date | — | 終了日 |

**備考**

- 期間が指定された場合、`startDate`〜`endDate` の日数分 `shiori_days`（◯日目）を自動生成する。
- 作成者は `shiori_members.role = owner` として参加する。

## 5. 写真系 API（アルバム）

### 5.1 写真一覧取得

| 項目 | 内容 |
|------|------|
| Method | `GET` |
| Endpoint | `/api/itineraries/{id}/albums` |
| 認証 | 必要（参加メンバー） |
| 概要 | 指定しおりに紐づく写真一覧を取得する |

**クエリパラメータ**

| 名前 | 型 | 説明 |
|------|-----|------|
| `sort` | string | 並び順。`likes` でいいね数順。未指定時は日付順（デフォルト） |
| `userId` | uuid | 特定ユーザーが登録した写真のみ取得 |
| `dayId` | uuid | 特定日の写真のみ取得（日付絞り込み） |

**レスポンス（例）**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `id` | uuid | 写真ID（`albumId`） |
| `dayId` | uuid | 日次ページID |
| `userId` | uuid | 投稿者ID |
| `imageUrl` | string | 画像URL |
| `isDeleted` | boolean | 削除済み（黒画像表示） |
| `likeCount` | int | いいね数 |
| `createdAt` | datetime | 登録日時 |

---

### 5.2 写真登録

| 項目 | 内容 |
|------|------|
| Method | `POST` |
| Endpoint | `/api/itineraries/{id}/albums` |
| 認証 | 必要（参加メンバー） |
| 概要 | 指定しおり・日付に対して写真を登録する（1日ごとに1人1枚） |

**リクエスト（例）**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `dayId` | uuid | ○ | 日次ページID |
| `image` | file | ○ | 画像ファイル |

**備考**

- `UNIQUE (day_id, user_id)` により 1日1人1枚を保証する。
- 画像本体はオブジェクトストレージに保存し、DB にはパスのみ保持する。

---

### 5.7 いいね

| 項目 | 内容 |
|------|------|
| Method | `POST` |
| Endpoint | `/api/albums/{albumId}/likes` |
| 認証 | 必要（参加メンバー） |

## 6. コメント系 API

しおり内の記述要素（タイトル、◯日目、ロードマップ予定1件、写真など）それぞれに単体でコメントできる。  
コメント対象は `target_type` + `target_id` + `target_field` で識別する（[データベース設計.md](./データベース設計.md) 参照）。

### 6.1 しおりコメント取得

| 項目 | 内容 |
|------|------|
| Method | `GET` |
| Endpoint | `/api/itineraries/{id}/comments` |
| 認証 | 必要（参加メンバー） |
| 概要 | 指定しおりに紐づくコメント一覧を取得する |

**クエリパラメータ（任意）**

| 名前 | 型 | 説明 |
|------|-----|------|
| `targetType` | string | コメント対象種別 |
| `targetId` | uuid | コメント対象ID |
| `targetField` | string | コメント対象フィールド |

---

### 6.2 しおりコメント登録

| 項目 | 内容 |
|------|------|
| Method | `POST` |
| Endpoint | `/api/itineraries/{id}/comments` |
| 認証 | 必要（参加メンバー、コメント解放済み） |
| 概要 | 指定しおりにコメントを投稿する |

**リクエストボディ（例）**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `body` | string | ○ | コメント本文 |
| `targetType` | string | ○ | `shiori` / `shiori_day` / `roadmap_item` / `photo` |
| `targetId` | uuid | ○ | 対象行のID |
| `targetField` | string | — | `shiori` / `shiori_day` の場合は必須 |

**備考**

- `is_comment_open = false` の場合は投稿不可（`403 Forbidden`）。

---

### 6.3 コメント変更

| 項目 | 内容 |
|------|------|
| Method | `PUT` |
| Endpoint | `/api/comments/{commentId}` |
| 認証 | 必要（投稿者本人） |
| 概要 | 既存コメントの内容を編集する |

**リクエストボディ（例）**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `body` | string | ○ | 新しいコメント本文 |

---

### 6.4 コメント削除

| 項目 | 内容 |
|------|------|
| Method | `DELETE` |
| Endpoint | `/api/comments/{commentId}` |
| 認証 | 必要（投稿者本人） |
| 概要 | 既存コメントを削除する |

---

### 6.5 写真コメント取得

| 項目 | 内容 |
|------|------|
| Method | `GET` |
| Endpoint | `/api/albums/{id}/comments` |
| 認証 | 必要（参加メンバー） |
| 概要 | 指定写真に紐づくコメント一覧を取得する |

**備考**

- 内部的には `target_type = photo` のコメントとして取得する。

---

### 6.6 写真コメント登録

| 項目 | 内容 |
|------|------|
| Method | `POST` |
| Endpoint | `/api/albums/{id}/comments` |
| 認証 | 必要（参加メンバー、コメント解放済み） |
| 概要 | 指定写真にコメントを投稿する |

**リクエストボディ（例）**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `body` | string | ○ | コメント本文 |
