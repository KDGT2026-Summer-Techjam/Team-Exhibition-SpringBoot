# しおりアプリ 概要・画面一覧

デザイン（色・レイアウト・見た目）は含めない。必要な画面と、各画面に置く要素・操作だけをまとめる。

関連: [要件定義.md](./要件定義.md)

---

## 1. アプリ概要

旅行・イベントの「しおり」を複数人で共有・編集する Web アプリ。

| 項目 | 内容 |
|------|------|
| 目的 | 旅の予定・メモ・写真・コメントを、参加メンバーで一緒に残す |
| 主な利用者 | しおりを作成する人（作成者／管理者）と、招待されて参加するメンバー |
| コア機能 | アカウント、しおりの作成・参加・退出、日ごとの予定編集、コメント、写真アルバム、メンバー管理 |
| 認証 | ユーザー名・メールアドレス・パスワードで登録／ログイン |
| しおり単位の鍵 | しおりごとにパスワードがあり、招待参加時に入力する |

### 役割の違い（画面要素の出し分けに影響）

| 役割 | できること（画面上で必要な操作） |
|------|----------------------------------|
| 未ログイン | 新規登録・ログイン・招待受領（参加） |
| 一般メンバー | しおり一覧・内容の閲覧／編集（権限がある場合）・写真・コメント・退出・設定 |
| しおり作成者（管理者） | 上記に加え、編集権限・コメント解放の切替、代表写真の選定、しおり管理（メンバー BAN・設定変更・削除） |

### 横断ルール（画面要素に効く制約）

- アカウント／しおりのパスワードは **英数字 10 文字以上**
- しおり期間から **日ごとのページが自動生成** される
- 写真は **1 日につき 1 人 1 枚**。削除後は黒い画像に置き換わる
- コメントは、しおり内の各記述要素に対して個別に付けられる（解放設定が ON のとき）
- しおり管理画面は **作成者のみ**

### 3.5 しおり内容画面

#### しおり全体ヘッダーまわり

| 要素 | 種別 | 対象 | 説明 |
|------|------|------|------|
| しおりタイトル | 表示／編集 | 全員（編集は権限による） | コメント対象にもなる |
| タイトル補足 | 表示／編集 | 同上 | コメント対象 |
| 期間 | 表示／編集 | 同上 | コメント対象。変更は管理画面でも可 |
| 戻る | 操作 | 全員 | しおり一覧へ |
| 写真一覧への導線 | リンク | 全員 | 写真一覧画面へ |
| しおり管理への導線 | リンク | **作成者のみ** | しおり管理画面へ |
| しおり編集権限（ON／OFF） | 切替 | **管理者のみ** | メンバーの編集可否 |
| しおりコメント解放（解放／未解放） | 切替 | **管理者のみ** | コメント機能の可否 |
| お約束 | 表示／編集 | 権限による | 旅のルール。コメント対象 |

#### 日ごとのページ（期間から自動生成）

日の切り替え（タブ／ページャー等）と、1 日分の内容ブロックが必要。

| 要素 | 種別 | 対象 | 説明 |
|------|------|------|------|
| ◯日目の切り替え | ナビ | 全員 | 期間内の各日へ移動 |
| その日のタイトル | 表示／編集 | 権限による | コメント対象 |
| ロードマップ（予定一覧） | 表示／編集 | 権限による | カレンダー形式。予定ごとに時刻・内容・任意の使用金額 |
| ロードマップ 1 件の追加／編集／削除 | 操作 | 権限による | コメントは「時刻付き 1 件」単位 |
| 備考 | 表示／編集 | 権限による | その日のメモ。コメント対象 |
| 概算 | 表示／編集 | 権限による | 1 日単位の概算費用。コメント対象 |
| 代表写真 | 表示 | 全員 | 登録写真から選んだ 1 枚をその日の代表として表示 |
| 代表写真の選定 | 操作 | **しおり管理者のみ** | その日の写真候補から 1 枚選択 |
| お約束（しおり全体に置く場合はヘッダー側でも可） | 表示／編集 | 権限による | 要件上、日ごと要素としても定義 |

#### コメント（各記述要素ごと）

コメント解放が ON のとき、次の各要素の近くに付ける。

| 要素 | 種別 | 説明 |
|------|------|------|
| コメント追加トリガー（要素横の＋） | 操作 | 対象要素に対してコメント開始 |
| コメント一覧（対象の近く） | 表示 | その要素へのコメント |
| コメント投稿 | 操作 | 新規投稿 |
| コメント編集 | 操作 | 自分のコメント想定（要件は投稿／編集／削除） |
| コメント削除 | 操作 | 削除 |

**コメント対象となりうる要素**

- しおりタイトル、タイトル補足、期間
- ◯日目タイトル、ロードマップの予定 1 件、備考、概算、代表写真、お約束
- 写真（詳細は写真一覧側）

## 4. 画面間の主な流れ

```
新規登録 ⇄ ログイン
              ↓
         しおり一覧 ⇄ 設定
           │    ↑
           │    └─ 退出（一覧に留まる）
           ├─ しおり作成 → しおり内容
           └─ しおりカード → しおり内容
                                ├─ 写真一覧（詳細・いいね・コメント）
                                └─ しおり管理（作成者のみ）

招待リンク → 招待受領 →（加入）→ しおり内容
```

| 設定 | ユーザー名・パスワード | 変更・ログアウト |
